# TDOCS canonical facts JA

> 公開文言・FAQ・多言語翻訳で参照する正本メモ。実装変更時はここも更新する。

## Product

- App name: Time Defense Calendar
- Android向け個人用カレンダー。
- 核となるメッセージ: 予定表ではなく、時間を守る盾。
- 予定、Todo、Memo、Timetable、Home Widgetを扱う。

## Trial

- 30日Trialは、インストール後30日ではなく、Time Defenseを初めて開いた時点から30日間。
- Trial開始に購入手続きは不要。
- Trial終了後に自動課金なし。
- 明示的にProを購入しない限り課金なし。
- Trial終了後も保存済みEvent / Todo / Memoは削除されない。

## Free

- Event: 手動で新しく作成できる予定は1日5件まで。
- 予定を削除しても、その日の作成可能回数は戻らない。
- これは1日に表示できる予定数の上限ではない。
- Todo: 現在保存している件数が30件まで。
- Memo: 現在保存している件数が30件まで。

## Pro

- Event / Todo / Memo の作成上限解除。
- Timetable Deployment。
- Custom Stamp。
- Pro決済はGoogle Playの購入画面で行われる。
- Time Defense Calendarはクレジットカード番号を収集・保存しない。

## Timetable

- Timetable Deployment自体はPro / active Trial機能。
- Timetableで生成された予定は通常予定として保存される。
- Trial終了後も生成済み予定は表示・編集・削除できる。
- 繰り返しと通知も通常の予定と同じ条件で継続する。

## Caution

- 通知・Widgetは端末権限、省電力設定、端末メーカー独自制御の影響を受ける場合がある。
- Private表示は完全秘匿保証ではない。
