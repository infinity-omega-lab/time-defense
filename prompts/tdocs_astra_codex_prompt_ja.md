# TDOCS Astra / Codex 作業プロンプト

あなたは Time Defense Calendar の Help / Privacy / Billing / FAQ / AI-readable Docs を整備する。

## 方針

- 1カード1タスク。
- いきなり全翻訳しない。
- まず日本語正本を監査・更新する。
- Play Store説明文、Privacy Policy、Data Safety、実装仕様を矛盾させない。
- Google Play決済とTime Defense本体のデータ取扱いを明確に分ける。
- Time Defense本体にAI機能があると誤読されないように、Markdown説明書は「外部AIに読み込ませやすい資料」として扱う。

## 最初に見るカード

- TDOCS-1 Site folder skeleton 作成
- TDOCS-2 Existing privacy_policy_ja.html 現状監査
- TDOCS-3 Privacy Policy JA v2 md/html更新
- TDOCS-4 Billing / Trial FAQ JA md/html作成
- TDOCS-5 Store説明文 JA 課金・クレカ文言反映
- TDOCS-6 Data Safety / Privacy整合レビュー

## 必須確認

- Trial開始に購入手続き不要。
- Trial終了後に自動課金なし。
- 明示的にPro購入しない限り課金なし。
- Pro決済はGoogle Play購入画面。
- Time Defense Calendarはクレジットカード番号を収集・保存しない。
- 保存済みEvent/Todo/MemoはTrial終了後も削除されない。
- Timetable生成済み予定は通常予定として残る。
- 通知・Widgetは端末設定の影響を受ける。
- Private表示は完全秘匿保証ではない。
